# RUDRAM Hackathon Demo Presentation Script (5-10 Mins)

1. **Dashboard & Common Operating Picture** (`/dashboard/`): Click "⚡ START FLOOD DEMO" to initialize live telemetry.
2. **AI Risk Prediction** (`/risk/`): Run XGBoost inference and show SHAP feature contribution breakdown.
3. **GIS Multi-Hazard Studio & Shelters** (`/map/` & `/shelters/`): Toggle 21 spatial layers and run multi-criteria shelter matching.
4. **Evacuation Pathfinding** (`/evacuation/`): Compare flood-penalized Route A vs. safe elevated Route B with Safety Scores.
5. **Satellite SAR Lab & AI Assistant** (`/satellite/` & `/assistant/`): Drag Before/After radar inundation slider and query AI Copilot.
6. **Official Report Export** (`/reports/`): Generate and download publication-ready ReportLab PDF Situation Report.
